# Superstore Sales & Profit Dashboard

Interactive Power BI dashboard built using the Superstore dataset.

## Project Overview

This project analyzes sales, profit, orders, discounts, regions, categories, sub-categories, states, and products using Microsoft Power BI.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Superstore Dataset
